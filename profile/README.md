### dissolve

Animated components for React Native and React. Interfaces that break into grains and rebuild themselves.

Copy them into your project, or let your agent build with them. The code is yours.

```bash
npx dissolve-ui add elastic-slider
```

Use it with your agent (Claude Code, Codex, Cursor):

```bash
curl -fsSL dissolve.rselmi.com/mcp.sh | sh
```
